# אריאל ספר · קביעת תור

אתר קביעת תורים לאריאל, ספר גברים בחולון. מתארח ב-GitHub Pages:
https://chlomo111-bit.github.io/ariel-barber/

- `index.html` – האתר (לקוחות + ניהול בכתובת `#admin` או "כניסת מנהל" בתחתית)
- `config.json` – הגדרות ציבוריות, שעות תפוסות (בלי פרטי לקוחות) וכתובת הבוט
- `data.enc.json` – תורים ולקוחות, מוצפנים. כל משתמש ניהול פותח אותם עם הסיסמה שלו
- `bot/` – בוט הוואטסאפ שרץ על המחשב

## בוט הוואטסאפ
מה הוא עושה: שולח ללקוח קוד אימות, קובע את התור ביומן, שולח אישור עם קישור ליומן,
מודיע לאריאל על כל תור חדש, ושולח תזכורת לפני התור.

הפעלה ב-Mac:
1. התקן Node.js (LTS) מ-https://nodejs.org ו-Homebrew מ-https://brew.sh
2. באתר: ניהול > כללי > משתמשי ניהול > הוסף משתמש `bot` עם סיסמה
3. בתיקייה `bot`: לחיצה כפולה על `start-bot.command`. בפעם הראשונה ייפתח `.env`: מלא GH_TOKEN, ADMIN_USER, ADMIN_PASSWORD ושמור
4. שוב לחיצה כפולה. סרוק את ה-QR (בטרמינל או באתר בלשונית וואטסאפ) מהטלפון של מספר הבוט:
   וואטסאפ > הגדרות > מכשירים מקושרים > קישור מכשיר
5. המחשב צריך להישאר דלוק עם החלון פתוח. אם הבוט כבוי, האתר חוזר אוטומטית לשליחת בקשה ידנית בוואטסאפ.
